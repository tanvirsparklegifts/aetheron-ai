# AETHERON — Product Requirements

## Identity
AETHERON — THE AUTONOMOUS INTELLIGENCE. YOUR WORLD. YOUR INTELLIGENCE. Powered by EliteAxis Global.

## Objective
Build a personal executive intelligence platform that helps people understand context, research, plan, and execute authorized work across personal and professional domains.

## Product surfaces
- Web dashboard: onboarding, conversation, task center, memory controls, integrations, settings.
- Windows companion: user-approved browser, file, and desktop workflows.
- Android companion: voice, notifications, share-sheet handoff, approved mobile workflows.
- Cloud Brain: identity-aware orchestration, model routing, retrieval, task state, policy checks, audit events.

## User types
- Public user: isolated account, memory namespace, files, integrations, and permissions.
- Owner/admin: platform operations; admin status does not imply unrestricted access to private user conversations.
- Support/security operator: narrow, time-limited access for approved incident handling, with reason codes and audit.

## Planned capabilities
Bangla and English interaction; user-controlled memory; source-backed research; project/business workspaces; task planning; specialized agent routing; authorized integrations; cross-device continuity.

## Action policy
Read-only actions may run within granted scopes. External messages, public posts, purchases, payments, legal commitments, account changes, and destructive operations require explicit confirmation. High-impact actions show a preview of target, content, scope, and consequences. Never claim completion until a tool confirms success. Refuse unlawful, deceptive, or unsafe requests.

## Commercial hypothesis
Free: fair-use core assistant, research, and productivity features with transparent capacity limits. Premium: proposed $5/month commerce workflow tier, subject to unit-economics validation; product cost, shipping, taxes, and merchant charges are separate. Disclose affiliate relationships and do not bias recommendations. Do not promise unlimited expensive model access.

## Initial non-goals
Unsupervised financial-account control; autonomous professional legal/medical/financial services; hidden impersonation; covert device surveillance; fully autonomous high-impact actions.

## Public beta release gates
Tenant isolation, authorization, secret-leak and prompt-injection tests; audit verification; data export/deletion; incident response; documented limitations.
