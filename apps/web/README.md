# AETHERON Web

Premium dashboard prototype built with Next.js, React, TypeScript, and Lucide icons.

## Run locally

    npm install
    npm run dev

Open http://localhost:3000.

## Current scope
- Responsive luxury dark interface with cyan and violet accents.
- Workspace navigation and dashboard cards.
- Local-only prompt interaction preview.
- No connected model, account system, persistence, or real tool execution yet.

The prompt box intentionally displays a prototype notice instead of pretending cloud AI is connected.
